# Product Vision & Overview

## One-Liner

**Host a Party** is an event-scoped social connection platform where users host or join real-world events and use a Tinder-style "Party Mode" to connect with fellow attendees — removing the awkwardness of approaching strangers at a party.

---

## Problem Statement

Going to events and parties alone is intimidating. Even at social gatherings, people struggle with the initial friction of approaching someone new. Existing dating apps are context-free — they lack the shared experience that makes connections meaningful.

## Solution

Host a Party solves this by scoping connections to live events:

1. **Hosts** create events (house parties, rooftop nights, meetups)
2. **Attendees** discover nearby events and request to join
3. **At the event**, Party Mode activates — attendees can swipe on each other (like a dating app) to express interest
4. **Mutual interest** creates a match, unlocking private chat — all within the context of the event they're both at

## Unique Selling Proposition (USP)

**Event-scoped connections.** Unlike Tinder/Bumble where you match with strangers from anywhere, Host a Party ensures every connection shares a real-world experience. This creates:

- Higher-quality matches (you're both at the same event)
- Built-in conversation starters ("How do you know the host?")
- A safer environment (verified event attendance + GPS check-in)

## Target Audience

| Segment | Description |
|---------|-------------|
| **Primary** | 18-35 year-olds in urban areas who attend social events, house parties, and meetups |
| **Secondary** | Event organizers, community builders, social club hosts |
| **Tertiary** | Venues and brands looking to host interactive social experiences |

## Revenue Model (Future)

| Stream | Description |
|--------|-------------|
| Premium events | Hosts can charge an entry fee (platform takes a cut) |
| Super Likes | Limited daily super likes; buy more with in-app purchase |
| Boost | Boost your profile to the top of the swipe stack |
| Promoted Events | Hosts pay to appear in "Featured" discover section |

---

## Success Metrics (MVP)

| Metric | Target |
|--------|--------|
| Events created per week | 50+ |
| Join request conversion rate | > 40% |
| Party Mode engagement (swipes per live event) | > 20 per user |
| Match rate | > 15% of swipes |
| Message rate post-match | > 60% |
| Day-7 retention | > 30% |
